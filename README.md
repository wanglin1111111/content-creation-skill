# 内容创作技能包

面向文章、文案与短视频脚本的 AI 辅助创作流程，覆盖从选题构思到多平台分发的完整链路。

## 四项核心能力

| 能力 | 作用 | 产出 |
| --- | --- | --- |
| `create-outline` | 按主题生成文章结构 | 3~5 个标题备选、论点结构、段落顺序、素材提示 |
| `polish-text` | 润色已有文本 | 流畅度、生动性、逻辑严密性、情感共鸣四个维度的优化 |
| `generate-ideas` | 批量生成创意 | 标题创意、切入角度、内容形式、话题方向 |
| `adapt-platform` | 一稿多平台 | 小红书 / 抖音 / 公众号 / 微博 / 知乎 / B 站 的适配版本 |

## 适用场景

- **新媒体运营**：规划选题 → 批量标题 → 多平台改写 → 关键文案润色
- **品牌营销**：产品故事线 → 创意概念与 slogan → 分渠道物料
- **知识付费**：课程大纲 → 痛点话题 → 易懂化改写 → 引流脚本
- **电商带货**：卖点提炼 → 直播话术流程 → 详情页文案 → 平台素材

## 内置方法

- 标题五原则：数字、悬念、痛点、利益、共鸣
- 结构模型：AIDA（营销）、SCQA（深度文章）、金字塔原理（专业论述）
- 平台速查表：各平台内容特点、建议字数与关键要素

## 使用方式

将目录放入 Agent 的 skills 目录。标准流程为：明确目标 → 结构规划 → 素材准备 → 初稿 → 润色 → 多平台适配 → 发布复盘；时效性内容可走「热点 → 创意 → 适配 → 发布」的快速流程。
